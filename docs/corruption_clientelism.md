# Corruption & Clientelism Runtime Layer

## Goal

Corruption is a hidden power mechanism integrated into cabinet/ministry/coalition/territory loops.
It provides short-term gains but accumulates medium/long-term systemic risks.

## Three behavior levels

1. **Soft clientelism**
   - loyal appointments, patronage distribution
   - short-term discipline + local machine cohesion
   - long-term merit decay and effectiveness loss

2. **Gray schemes**
   - informal resource routing, coalition maintenance via flows
   - stronger cash/network/loyalty gains
   - much higher exposure and memory accumulation

3. **Heavy capture**
   - ministry behaves as rent extraction machine
   - very high short-term control
   - existential blast risk on exposure

## Core runtime variables

- `corruption_pressure`
- `corruption_yield`
- `exposure_risk`
- `corruption_memory`
- `corruption_sensitivity`
- cabinet-wide `corruption_load`

## Portfolio corruption profile

Each portfolio defines:
- `rent_potential`
- `patronage_value`
- `visibility`
- `blast_radius`

## Tick placement

Corruption logic is executed inside cabinet operating phase (phase 6), then impacts:
- coalition stability phase (phase 7)
- late public opinion phase (phase 8)
- next-turn headlines/hooks (phase 10)

## Trade-off design

Short-term upside:
- gray fund growth
- network acceleration
- discipline/lobby loyalty support

Long-term cost:
- cabinet performance degradation
- trust erosion on exposure
- higher scandal hooks and coalition fragility
- territorial protest sensitivity growth
